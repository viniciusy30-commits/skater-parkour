# Visualizador v99 — Guerreiro + Mercenário

`guerreiro-visualizador-v99.html` é gerado por `tools/build_v99.py` (motor do Guerreiro vindo do v98 + shell novo em `src/`).
Os dados do Mercenário vêm de `tools/mercenario/` (leitor de `.uasset`, retarget para o rig Tripo, encaixe das lâminas, exportação no formato do v98).
Os binários (GLB, pacote de animações, HTML final) não ficam no git; o HTML final é publicado como asset de release.
